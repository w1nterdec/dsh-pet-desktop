## 未发布 — 跨平台扩展

- 新增 macOS DMG/ZIP、Linux AppImage/Debian/tar.gz 目标和架构校验，修复 macOS Electron 缓存路径推导。
- 新增 macOS 原生应用菜单、Dock 恢复入口、托盘失败恢复与 Linux XDG 自启动；Wayland 优先使用可用的 XWayland 并提示系统限制。

- 新增桌面多平台与 Android 构建检查、素材包安全测试、原生导入交互测试与 Gradle Wrapper。
- 正式签名、macOS 公证、真实设备兼容性验收与外部发行由独立发布流程完成。
